📖 插件开发指南

插件是放在 scripts/plugins/ 目录下的独立 JS 文件：

module.exports = {
  name: 'MyPlugin',
  description: '说明文字',
  hook: 'eventSprite',
  tags: ['MY_TAG'],
  process: function(ev, ctx) {
    var m = ev.note.match(//);
    if (m) {
      ctx.shiftX = (ctx.shiftX || 0) + (parseInt(m[1], 10) || 0);
      ctx.shiftY = (ctx.shiftY || 0) + (parseInt(m[2], 10) || 0);
    }
  }
};

可用的钩子（hook）

eventSprite渲染事件精灵时调用，可修改偏移量
