    📖 插件开发指南

    插件是放在 scripts/plugins/ 目录下的独立 JS 文件，每个文件导出一个插件对象：

    module.exports = {
  name: 'MyPlugin',        // 插件名称
  description: '说明文字',  // 简短描述
  hook: 'eventSprite',     // 钩子：eventSprite
  tags: ['MY_TAG'],        // 声明的 note 标签（用于识别）

  process: function(ev, ctx) {
    // ev:  事件对象 { x, y, pages, note, ... }
    // ctx: 上下文 { shiftX, shiftY }
    // 修改 ctx 来影响精灵渲染
    var m = ev.note.match(//);
    if (m) {
      ctx.shiftX = (ctx.shiftX || 0) + (parseInt(m[1], 10) || 0);
      ctx.shiftY = (ctx.shiftY || 0) + (parseInt(m[2], 10) || 0);
    }
  }
};

    可用的钩子（hook）

    eventSprite渲染每个事件精灵时调用，可修改偏移量

    测试插件

    运行渲染命令查看效果：

    node scripts/render-maps.js "游戏目录" 地图ID

    如果插件有 tags 声明，渲染时会自动显示识别状态。
